HTML DOM

The HTML DOM (Document Object Model) represents this page as a tree of nested elements. For example, this <section> below has an <h3> and a <ul> as direct children, and that <ul> in turn has three <li> elements as its own children.

Sample nested list for DOM inspection

  • Child: <h3 id="dom-demo-heading">
